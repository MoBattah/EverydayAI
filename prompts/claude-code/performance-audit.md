Audit the codebase for meaningful performance issues — N+1 queries, unnecessary re-renders, memory leaks, blocking operations on the main thread, missing indexes, unbounded data fetching, expensive computations in hot paths, and redundant API calls. Ignore the hardcoded API key security issue. Ignore code style, naming, and formatting. For each issue found: describe the bottleneck, estimate the severity (high/medium/low), plan the optimization, then implement it. Start with the highest-impact issues first.
